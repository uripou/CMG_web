# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Static HTML/CSS assets for **Centre Mèdic Granollers (CMG)** — a medical centre in Granollers, Catalonia. Content is written in Catalan.

## Stack

Pure HTML + CSS (no build tools, no frameworks, no dependencies). Files are opened directly in a browser or screenshotted for social media use.

## Design system

- **Primary colour:** `#0ABAB5` (teal)
- **Font:** Montserrat (Google Fonts), weights 300 / 400 / 600 / 700 / 800
- **Canvas size:** 1080×1080 px (Instagram square format)
- **Logo:** inline SVG shield with a white cross and the initials CMG

## Git workflow

After every change: commit with a clean, descriptive message and push to `origin/master` (GitHub: `uripou/CMG_web`).
